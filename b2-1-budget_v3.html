핵심 Python 개념

“정의”보다 프로젝트에서 왜 썼는지에 초점을 둡니다.

Generator

yield = 한 건씩 전달

Repository의 iter_transactions()가 JSONL을 한 줄씩 읽어 거래를 하나씩 넘깁니다.

장점: 파일 전체를 한 번에 메모리에 올리지 않음.

Decorator

@safe_entry = 입구의 안전요원

main()을 한 번 감싸 공통 오류 메시지와 종료 코드 1을 처리합니다.

장점: CLI/Service/Repository에 같은 try/except 반복 감소.

Type Hint

입출력 계약 표시

month: str, -> int | None처럼 함수가 기대하는 자료형을 보여줍니다.

실행을 강제하는 기능이 아니라 사람이 이해하고 IDE가 검사하기 쉽게 하는 표지판.

6

JSONL · CSV · 안전한 수정/삭제

저장 형식과 데이터 안전성을 함께 이해합니다.

JSONL은 내부 영구 저장

거래 한 건이 JSON 객체 한 줄이므로 Transaction 구조와 잘 맞고, 한 줄씩 읽는 Generator와 연결하기 쉽습니다.

{"id":"...","type":"expense","date":"2026-09-16",...}
{"id":"...","type":"income","date":"2026-09-17",...}

CSV는 외부 교환

사람이 표로 보기 쉽고 Excel 같은 다른 프로그램과 주고받기 편해서 import/export 형식으로 사용합니다.

date,type,category,amount,memo,tags
2026-09-16,income,salary,1000000,용돈수입,test

update / delete는 왜 .tmp 파일을 거칠까?

원본 JSONL 읽기→.tmp에 새 내용 완성→성공 시 replace()→원본 교체

원본 파일을 직접 한 줄씩 고치는 대신 새 파일을 완성한 뒤 교체해, 중간 실패로 원본이 깨질 위험을 줄입니다.
