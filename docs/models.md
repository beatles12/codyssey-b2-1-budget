# models.py: 거래 모양

`Transaction`은 거래 한 건의 필드를 정의하는 프로젝트 클래스입니다. `dataclasses.dataclass`와 `field`는 Python 표준 기능입니다. `dataclass`는 데이터 구조를 선언하기 위한 표준 데코레이터이고 사용자 정의 데코레이터는 `__main__.py`의 `main()`에만 적용합니다. `repository.py`와 `service.py`가 이 클래스를 사용합니다.

## 함수와 호출 관계

이 파일에 정의된 함수는 없습니다.

## 흐름

`budget_app/models.py`의 내용은 위에서 설명한 모듈과 함수에서 사용됩니다.
