# __main__.py: 프로그램 시작점

`python -m budget_app`을 실행하면 이 파일의 `main()`이 `cli.run_cli()`를 호출합니다. 오류 처리 데코레이터는 이 `main()`에 한 번 적용됩니다.

## 함수와 호출 관계

| 함수 | 역할 | 프로젝트 정의 기능 호출 | Python 표준 기능 사용 |
|---|---|---|---|
| `main` | CLI를 시작하면서 공통 오류 처리를 한 번 적용한다 | `run_cli` | 주요 직접 호출 없음 |

## 흐름

`budget_app/__main__.py`의 내용은 위에서 설명한 모듈과 함수에서 사용됩니다.
