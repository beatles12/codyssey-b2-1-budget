# decorators.py: 공통 오류 안내

`safe_entry`는 프로젝트 정의 데코레이터입니다. `__main__.py`의 `main()`에 한 번 붙고, 일반 본문의 오류를 한곳에서 안내합니다.

## 함수와 호출 관계

| 함수 | 역할 | 프로젝트 정의 기능 호출 | Python 표준 기능 사용 |
|---|---|---|---|
| `safe_entry` | 진입점에서 사용자 오류를 안내하고 실패 코드로 종료한다 | 직접 호출 없음 | `print` |
| `wrapper` | 감싼 함수를 실행하고 예외를 공통 방식으로 처리한다 | 직접 호출 없음 | `print` |

## 흐름

`budget_app/decorators.py`의 내용은 위에서 설명한 모듈과 함수에서 사용됩니다.
